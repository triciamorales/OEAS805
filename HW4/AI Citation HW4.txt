To fix the FutureWarning in Seaborn, pass the hue argument alongside x and set legend=False.   
PNG

Solution
Update line 3 of your code to assign hue='architecture' and add legend=False:

Python
sns.barplot(
    data=results_df, 
    x='architecture', 
    y='test_accuracy', 
    hue='architecture', 
    palette='viridis', 
    legend=False
)
Why this happens
In newer versions of Seaborn (v0.13.0+), using palette without defining hue is deprecated. Assigning hue='architecture' applies the color palette across your x-axis categories, and legend=False keeps Seaborn from creating an unnecessary extra legend for the x-axis colors.

How do I make text larger in the markdown cells in jupyter notebook (browser version)

To make text larger in a Jupyter Notebook Markdown cell, use HTML tags or standard Markdown headers (#).

Method 1: Use Markdown Headers (Recommended)
Add one or more # symbols at the beginning of the line:

Markdown
# Very Large Text (Heading 1)
## Large Text (Heading 2)
### Medium-Large Text (Heading 3)
Method 2: Use Inline HTML with CSS
For precise control over exact font sizes, use an inline HTML <span> or <p> tag:

HTML
<span style="font-size: 24px;">This is 24px text</span>
Or relative sizes:

HTML
<span style="font-size: 150%;">This text is 50% larger</span>
Method 3: Use the HTML <font> Tag
You can also use the HTML <font> tag with a size attribute (scale from 1 to 7):

HTML
<font size="5">This text is size 5</font>
Tip: After entering any of these snippets in a Markdown cell, press Shift + Enter to render the formatted text.
